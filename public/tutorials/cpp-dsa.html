Modern C++ Foundations, Fast I/O & Compilation

Understand C++ compilation stages, modern standard features (C++17/20), namespaces, and high-speed I/O optimization for competitive programming.

1. Fast I/O Boilerplate for Online Judges

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

void fastIO() {
    // Untie cin from cout and disable C stdio sync for high-speed I/O
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
}

int main() {
    fastIO();
    int t;
    if (cin >> t) {
        while (t--) {
            int n;
            cin >> n;
            cout << "Output: " << (n * 2) << "\n"; // Prefer \n over endl (flushing overhead)
        }
    }
    return 0;
}
Performance Warning: endl vs \n
std::endl not only prints a newline character but also flushes the standard output stream buffer. In competitive programming loops with 100,000+ iterations, flushing each cycle causes Time Limit Exceeded (TLE). Always use '\n'.
💡 Knowledge Checks & Common Interview Questions
Why does cin.tie(NULL) improve performance?▼
By default, cin is tied to cout, meaning any read operation on cin automatically flushes cout to ensure prompts are displayed before input. Calling cin.tie(NULL) breaks this coupling, preventing unnecessary flushes and saving significant CPU time.

Pointers, Memory Layout & Smart Pointers

Master raw pointer arithmetic, stack vs heap allocation, reference qualifiers, and modern C++ smart pointers (unique_ptr, shared_ptr, weak_ptr).

1. Smart Pointers (C++11/14/17)

#include <iostream>
#include <memory>

struct Node {
    int val;
    std::shared_ptr<Node> next;
    Node(int v) : val(v), next(nullptr) {}
    ~Node() { std::cout << "Node " << val << " destroyed\n"; }
};

int main() {
    // 1. std::unique_ptr - Exclusive ownership (zero runtime overhead)
    auto uPtr = std::make_unique<int>(42);
    std::cout << "Unique val: " << *uPtr << "\n";

    // 2. std::shared_ptr - Reference counted ownership
    auto head = std::make_shared<Node>(10);
    head->next = std::make_shared<Node>(20);

    std::cout << "Head ref count: " << head.use_count() << "\n";
    return 0; // Automatically freed when leaving scope
}
Best Practice: make_unique & make_shared
Always prefer std::make_unique<T>() and std::make_shared<T>() over raw new. They ensure exception safety and allocate the control block and managed object in a single contiguous memory block.
💡 Knowledge Checks & Common Interview Questions
How does weak_ptr prevent circular reference memory leaks?▼
A std::weak_ptr observes an object managed by a std::shared_ptr without incrementing its reference count. When two objects reference each other using shared_ptr, reference counts never drop to 0, causing leaks. Replacing one direction with weak_ptr resolves cyclic ownership.
Module 3

Classes, RAII & Move Semantics

Understand Resource Acquisition Is Initialization (RAII), Rule of Five, rvalue references (&&), and std::move for high-performance memory management.

1. Rule of 5 and Move Constructor

#include <iostream>
#include <utility>

class DynamicBuffer {
private:
    int* data;
    size_t size;
public:
    DynamicBuffer(size_t s) : size(s), data(new int[s]) {}
    ~DynamicBuffer() { delete[] data; }

    // Move constructor: transfers ownership of resource without copying
    DynamicBuffer(DynamicBuffer&& other) noexcept : data(other.data), size(other.size) {
        other.data = nullptr;
        other.size = 0;
    }

    // Move assignment
    DynamicBuffer& operator=(DynamicBuffer&& other) noexcept {
        if (this != &other) {
            delete[] data;
            data = other.data;
            size = other.size;
            other.data = nullptr;
            other.size = 0;
        }
        return *this;
    }
};
💡 Knowledge Checks & Common Interview Questions
What does std::move actually do at runtime?▼
std::move is an unconditional cast to an rvalue reference (T&&). It emits no runtime instructions; it informs the compiler that the argument can be treated as a temporary, enabling move constructors or move assignments.

1. Custom Hash Struct for std::unordered_map

#include <iostream>
#include <unordered_map>

struct PairHash {
    template <class T1, class T2>
    size_t operator()(const std::pair<T1, T2>& p) const {
        auto h1 = std::hash<T1>{}(p.first);
        auto h2 = std::hash<T2>{}(p.second);
        return h1 ^ (h2 << 1);
    }
};

int main() {
    std::unordered_map<std::pair<int, int>, int, PairHash> gridMap;
    gridMap[{1, 2}] = 100;
    std::cout << "Value at (1,2): " << gridMap[{1, 2}] << "\n";
    return 0;
}

Stack, Queue & Monotonic Data Structures

Master LIFO/FIFO adapters, min-stack design, and Next Greater Element problems using Monotonic Stacks and Deques in O(N).

1. Monotonic Stack for Next Greater Element

#include <iostream>
#include <vector>
#include <stack>

std::vector<int> nextGreaterElement(const std::vector<int>& nums) {
    int n = nums.size();
    std::vector<int> res(n, -1);
    std::stack<int> st; // stores indices

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[i] > nums[st.top()]) {
            res[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }
    return res;
}

Two Pointers & Sliding Window Patterns

Solve contiguous subarray problems, minimum window substrings, and target sum pairs efficiently in linear O(N) time.

1. Dynamic Sliding Window (Length of Longest Substring)

#include <iostream>
#include <string>
#include <vector>
#include <algorithm>

int lengthOfLongestSubstring(const std::string& s) {
    std::vector<int> lastIdx(256, -1);
    int maxLen = 0, left = 0;

    for (int right = 0; right < (int)s.size(); ++right) {
        if (lastIdx[(unsigned char)s[right]] >= left) {
            left = lastIdx[(unsigned char)s[right]] + 1;
        }
        lastIdx[(unsigned char)s[right]] = right;
        maxLen = std::max(maxLen, right - left + 1);
    }
    return maxLen;
}

Binary Search Patterns & Answer Search Space

Binary search on monotonic sorted arrays, lower_bound / upper_bound mechanics, and Binary Search on the Answer (e.g. Koko Eating Bananas, Aggressive Cows).

1. Binary Search on Answer Space Pattern

#include <iostream>
#include <vector>
#include <numeric>
#include <algorithm>

bool isValid(const std::vector<int>& piles, int h, int k) {
    long long hours = 0;
    for (int p : piles) {
        hours += (p + k - 1) / k; // Ceil division
    }
    return hours <= h;
}

int minEatingSpeed(std::vector<int>& piles, int h) {
    int low = 1, high = *std::max_element(piles.begin(), piles.end());
    int ans = high;

    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (isValid(piles, h, mid)) {
            ans = mid;
            high = mid - 1; // Try smaller speed
        } else {
            low = mid + 1;  // Need faster speed
        }
    }
    return ans;
}

Linked Lists, Floyd's Cycle & LRU Cache

Pointer manipulation, in-place reversal, Floyd's Tortoise and Hare cycle detection algorithm, and building an O(1) LRU Cache.

1. LRU Cache Implementation (Hash Map + Doubly Linked List)

#include <iostream>
#include <unordered_map>
#include <list>

class LRUCache {
    int capacity;
    std::list<std::pair<int, int>> dll; // {key, value}
    std::unordered_map<int, std::list<std::pair<int, int>>::iterator> map;

public:
    LRUCache(int cap) : capacity(cap) {}

    int get(int key) {
        if (map.find(key) == map.end()) return -1;
        dll.splice(dll.begin(), dll, map[key]); // Move to front
        return map[key]->second;
    }

    void put(int key, int value) {
        if (map.find(key) != map.end()) {
            map[key]->second = value;
            dll.splice(dll.begin(), dll, map[key]);
            return;
        }
        if ((int)dll.size() == capacity) {
            int evictKey = dll.back().first;
            dll.pop_back();
            map.erase(evictKey);
        }
        dll.emplace_front(key, value);
        map[key] = dll.begin();
    }
};

Binary Trees, BSTs & Tree Traversals

1. Diameter of Binary Tree (Post-Order DFS)

struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

int maxDiameter = 0;
int maxDepth(TreeNode* root) {
    if (!root) return 0;
    int lh = maxDepth(root->left);
    int rh = maxDepth(root->right);
    maxDiameter = std::max(maxDiameter, lh + rh);
    return 1 + std::max(lh, rh);
}

Heaps, Priority Queues & Top-K Patterns

Binary heaps, heapify in O(N), max-heaps vs min-heaps in std::priority_queue, and Top-K Frequent Elements.

1. Top-K Frequent Elements using Min-Heap

#include <iostream>
#include <vector>
#include <unordered_map>
#include <queue>

std::vector<int> topKFrequent(std::vector<int>& nums, int k) {
    std::unordered_map<int, int> freq;
    for (int x : nums) freq[x]++;

    // Min-heap pair: {count, value}
    std::priority_queue<std::pair<int, int>, std::vector<std::pair<int, int>>, std::greater<>> minHeap;

    for (auto& [val, count] : freq) {
        minHeap.push({count, val});
        if ((int)minHeap.size() > k) minHeap.pop();
    }

    std::vector<int> result;
    while (!minHeap.empty()) {
        result.push_back(minHeap.top().second);
        minHeap.pop();
    }
    return result;
}

Graph Theory: BFS, DFS, Dijkstra & DSU

Adjacency lists, shortest path with Dijkstra, cycle detection, topological sorting (Kahn's algorithm), and Disjoint Set Union with path compression.

1. Disjoint Set Union (DSU / Union-Find) with Rank & Path Compression

#include <vector>
#include <numeric>

class DSU {
    std::vector<int> parent, rank;
public:
    DSU(int n) : parent(n), rank(n, 0) {
        std::iota(parent.begin(), parent.end(), 0);
    }

    int find(int i) {
        if (parent[i] == i) return i;
        return parent[i] = find(parent[i]); // Path compression
    }

    bool unite(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);
        if (rootI == rootJ) return false; // Cycle detected

        if (rank[rootI] < rank[rootJ]) parent[rootI] = rootJ;
        else if (rank[rootI] > rank[rootJ]) parent[rootJ] = rootI;
        else { parent[rootJ] = rootI; rank[rootI]++; }
        return true;
    }
};

Dynamic Programming: 1D, 2D Grid & Knapsack Patterns

Master overlapping subproblems, optimal substructure, memoization vs tabulation, 0/1 Knapsack, and Longest Common Subsequence (LCS).

1. 0/1 Knapsack Space-Optimized 1D DP

#include <iostream>
#include <vector>
#include <algorithm>

int knapsack01(int W, const std::vector<int>& wt, const std::vector<int>& val, int n) {
    std::vector<int> dp(W + 1, 0);

    for (int i = 0; i < n; ++i) {
        // Iterate backward to prevent reusing the same item multiple times
        for (int w = W; w >= wt[i]; --w) {
            dp[w] = std::max(dp[w], val[i] + dp[w - wt[i]]);
        }
    }
    return dp[W];
}
DP State Transitions
When reducing 2D DP dp[i][w] to 1D DP dp[w], always check whether the current state depends on values from the previous row. For 0/1 Knapsack, right-to-left iteration ensures previous states are not overwritten.
💡 Knowledge Checks & Common Interview Questions
How to identify whether a problem can be solved with DP?▼
Look for two primary traits: (1) Optimal Substructure: an optimal solution to the problem contains within it optimal solutions to subproblems, and (2) Overlapping Subproblems: the recursive solution revisits the same subproblems repeatedly rather than generating new ones each time.
