💡 ICSE/ISC Board & Placement Q&A
Q1: Why is Java considered both a compiled and an interpreted language? ▼
Java source code (.java) is first compiled by javac into platform-independent intermediate bytecode (.class). This bytecode is then interpreted and JIT-compiled by the target machine's JVM into native machine instructions during execution.

Loops, Nested Iterations & Series Generation

// Fibonacci Series Generation (First N terms):
public static void printFibonacci(int n) {
    int a = 0, b = 1;
    System.out.print("Fibonacci (" + n + " terms): ");
    for (int i = 0; i < n; i++) {
        System.out.print(a + " ");

Module 7 · Classes & Constructors

Classes, Constructors, `this`, `super` & Static Scope

Understand object instantiation, constructor overloading, constructor chaining, and memory sharing via `static`.

public class Student {
    // Static Variable: Shared across all instances in Method Area
    private static int totalEnrolled = 0;

    // Instance Variables: Unique to each instance on Heap
    private String name;
    private double gpa;

    // Parameterized Constructor with 'this' pointer disambiguation
    public Student(String name, double gpa) {
        this.name = name;
        this.gpa = gpa;
        totalEnrolled++;
    }

    // Constructor Chaining (Overloaded Constructor)
    public Student(String name) {
        this(name, 0.0); // Calls the parameterized constructor above
    }

    public static int getTotalEnrolled() {
        return totalEnrolled;
    }
}
Module 8 · Polymorphism

Method Overloading vs Dynamic Method Overriding

Understand Compile-time Early Binding vs Runtime Dynamic Method Dispatch via virtual method tables (vtable).

class BankAccount {
    protected double balance;

    public BankAccount(double balance) {
        this.balance = balance;
    }

    // Overridden Method in Parent
    public double calculateInterest() {
        return balance * 0.03; // Standard 3% interest
    }
}

class HighYieldSavings extends BankAccount {
    public HighYieldSavings(double balance) {
        super(balance);
    }

    // Dynamic Runtime Override with @Override Annotation
    @Override
    public double calculateInterest() {
        return balance * 0.07; // 7% High Yield interest
    }
}

public class Main {
    public static void main(String[] args) {
        // Polymorphic reference: Parent type pointing to Child instance
        BankAccount account = new HighYieldSavings(10000.0);
        System.out.println("Interest: ₹" + account.calculateInterest()); // 700.0 (Runtime dynamic dispatch)
    }
}

Module 10 · Arrays & Matrices

1D & 2D Array Algorithms: Search, Sort & Matrix Math

Binary search, selection sort, and 2D matrix transpose / diagonal manipulations.

// Binary Search on Sorted Array: O(log N)
public static int binarySearch(int[] arr, int target) {
    int low = 0, high = arr.length - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] == target) return mid;
        if (arr[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1; // Not found
}
Module 11 · Strings & Memory

String Constant Pool, Immutability & StringBuilder

Understand why Strings are immutable, String Pool memory deduplication, and high-performance `StringBuilder` buffers.

public class StringPoolDemo {
    public static void main(String[] args) {
        String s1 = "EduHub";            // Placed in String Constant Pool
        String s2 = "EduHub";            // Reuses reference from pool
        String s3 = new String("EduHub");// Creates distinct object on Heap

        System.out.println(s1 == s2);      // TRUE (Identical memory references)
        System.out.println(s1 == s3);      // FALSE (Distinct memory addresses)
        System.out.println(s1.equals(s3)); // TRUE (Deep content value equality)
    }
}

Module 14 · Collections Framework

Java Collections Framework: Lists, Sets & HashMaps

Work with generic collections (`ArrayList`, `HashSet`, `HashMap`) and understand time complexity trade-offs.

import java.util.*;

public class CollectionsDemo {
    public static void main(String[] args) {
        // Fast random access: O(1) read
        List<String> studentList = new ArrayList<>();
        studentList.add("Aarav");
        studentList.add("Meera");

        // Key-Value Hashing: O(1) average lookup/put
        Map<String, Double> grades = new HashMap<>();
        grades.put("Aarav", 94.5);
        grades.put("Meera", 88.0);

        for (Map.Entry<String, Double> entry : grades.entrySet()) {
            System.out.println(entry.getKey() + " -> " + entry.getValue());
        }
    }
}
