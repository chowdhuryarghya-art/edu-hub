Q1: What makes a flowchart different from pseudocode? ▼
A flowchart is a diagrammatic representation of an algorithm using standardized geometric shapes connected by flowlines, whereas pseudocode is a structured, informal plain-text approximation of high-level programming logic.
Module 2 · Coordinates & Vectors

Stage Coordinate System & Vector Motion

Understand (X, Y) planes, rotation angles, direction vectors, costumes, and boundary clamping.

1. Cartesian Plane Geometry

The Scratch stage is a 480x360 pixel 2D Cartesian coordinate grid with origin (0, 0) centered on screen:

  • X Axis (Width): Ranges from -240 (far left) to +240 (far right).
  • Y Axis (Height): Ranges from -180 (bottom edge) to +180 (top edge).
  • Direction: 0° = Up, 90° = Right, 180° = Down, -90° = Left.
// Smooth Vector Glide Algorithm:
when green flag clicked:
  go to x: (-200) y: (0)
  point in direction (90)
  repeat (40):
    change x by (10)
    wait (0.02) secs
  if on edge, bounce
⚠️ Edge Clamping & Collisions

Using if on edge, bounce prevents sprites from vanishing off screen by detecting when bounding coordinates cross $|X| \ge 240$ or $|Y| \ge 180$.

Module 3 · State Management

Variables, Data Types & User Sensing Inputs

Master variable declaration, Global vs Local sprite scope, user input prompts, and arithmetic operators.

1. Variable Scope

  • Global Variables ("For all sprites"): Shared state accessible and mutable by every sprite and stage (e.g. GameScore, GlobalTimer).
  • Local Variables ("For this sprite only"): Instance variables private to an individual sprite or clone (e.g. velocityX, health).
// Dynamic Score Accumulator with User Input:
when green flag clicked:
  set [totalScore v] to (0)
  ask [Enter points earned:] and wait
  change [totalScore v] by (answer)
  say (join [Your Updated Score: ] (totalScore)) for (2) secs
